# Janicik 2028 — fake campaign site (class project)

Open `index.html` in a browser. No build step.

## Adding the candidate photo
Save the photo as `images/candidate.jpg`. It's used automatically for the homepage
backdrop, the Bio portrait, and the social-post avatars. A wide/landscape shot with
the face on the right side works best for the homepage.
